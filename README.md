## 🔧 Development Guidelines

### Code Organization
- Each system is a self-contained `UActorComponent` subclass
- Systems follow Unreal Engine coding standards
- All systems are Blueprint-spawnable components
- Consistent naming conventions across all phases

### Asset Organization
- **Blueprints**: All Blueprint assets including characters, items, abilities
- **Materials**: All material instances and material functions
- **Textures**: All texture files organized by type
- **Audio**: All sound files organized by category
- **Animations**: All animation montages and sequences
- **Maps**: All level files and world data

## 🚀 Build Instructions

1. Open the project in Unreal Engine 5
2. All systems are automatically compiled as part of the game module
3. Systems can be added to actors via the Components panel
4. All systems are Blueprint-accessible
