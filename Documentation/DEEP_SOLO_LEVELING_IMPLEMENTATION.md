```
Core Principles:

Combat Flow:

```

### **🗡️ Weapon Mastery System**
```
Weapon Classes (Elden Ring Depth):
Daggers:
- Lightning-fast attacks
- Critical strike bonuses
- Shadow assassination techniques
- Combo: Swift Strike → Shadow Step → Fatal Blow

Swords:
- Balanced offense/defense
- Versatile move set
- Skill chaining capabilities
- Combo: Slash → Parry → Counter → Flourish

Greatswords:
- Heavy damage, slow attacks
- Area-of-effect attacks
- Hyper armor during attacks
- Combo: Heavy Slam → Shockwave → Uppercut → Finisher

Spears:
- Extended reach advantage
- Keep enemies at distance
- Thrust combos and sweeps
- Combo: Jab → Sweep → Lunge → Impale

Fist Weapons:
- Unarmed combat mastery
- Rapid punch combinations
- Chi/energy channeling
- Combo: Jab → Hook → Uppercut → Energy Blast

Shadow Weapons:
- Summoned from defeated enemies
- Retain original monster abilities
- Can evolve and upgrade
- Combo: Summon → Command → Merge → Ultimate Attack
```
